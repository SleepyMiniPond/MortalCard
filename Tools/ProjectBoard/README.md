# 本機專案文件閱讀器

閱讀器直接查閱既有 Document 與目前工作計畫，提供進度總覽、任務步驟、驗收、歷史與文件閱讀。不改寫來源、不產生文件快照、不呼叫 AI API，沒有外部套件或雲端服務。

## 啟動與更新

1. 已安裝 Node.js 18 以上版本後，雙擊根目錄的「啟動專案閱讀器.cmd」。
2. 程式會在背景啟動本機服務，並以預設瀏覽器開啟 http://127.0.0.1:4317 。重複啟動會重用同一份專案的服務。
3. Document 更新後按網頁的「重新讀取」，或重新整理頁面；不需執行資料產生指令。

服務只綁定本機，無請求五分鐘後會自行結束。開啟的頁面每分鐘維持連線；若瀏覽器休眠導致服務結束，重新雙擊啟動檔即可。埠被其他服務或另一份專案占用時會回報錯誤，不會停止其他程式。

開發時也可以執行 node Tools/ProjectBoard/server.mjs，在終端查看訊息，按 Ctrl+C 停止。HTML 需要透過本機服務開啟。

## 目前工作

- 草稿及計畫仍放 .agents/working/，不移入 Document。
- .agents/working/目前工作.md 只用連結索引正在使用的檔案，不另存進度；不依日期將全部舊草稿判為進行中。
- 「目前工作」頁呈現各計畫中的目前步驟、最近完成、下一步、驗證結果、待確認事項與工作表格，也可展開完整原文。
- 此頁開啟時每五秒讀取目前計畫；有變更才更新畫面。AI 每次推進或驗證後先更新原計畫，頁面就反映相同資訊。
- 「待使用者確認」獨立於「已完成」。完成或暫停後從索引移除；草稿與索引都不納入 Git。

工作更新規則維護於根目錄 AGENTS.md。閱讀器不要求 Document 加入專用欄位或執行同步。

## 讀取與呈現

閱讀器適配現有的任務標題、狀態文字、工作表格、編號清單與文件連結；未辨識成任務的內容仍可閱讀原文。TODO 的同 ID 現況優先於歷史紀錄。

完成數量指已封存任務數，不是遊戲完成百分比。歷史測試結果不代表本次重新驗證。Mermaid 暫以原始碼呈現。Document 外的原始碼入口只顯示路徑提示，本服務不提供任意專案檔案下載。

文案直接表達資訊與操作。內文 18px，輔助資訊至少 16px，保留行距與文字對比。

## 維護與驗證

- reader.mjs：從來源檔案辨識任務與目前工作。
- server.mjs：唯讀 HTTP 服務，只提供閱讀器資產及文件讀取端點。
- start.mjs：檢查／啟動服務並開啟預設瀏覽器。
- dist/：前端 HTML、CSS 與 JavaScript，沒有建置步驟。
- reader.test.mjs：讀取、更新、索引與服務邊界測試，執行 node --test Tools/ProjectBoard/reader.test.mjs。

本工具位於 Assets 之外，不參與 Unity 編譯，也不推進遊戲主線的驗收狀態。
